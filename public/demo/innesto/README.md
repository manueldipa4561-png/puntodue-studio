# INNESTO — Progetto + Cantiere

Fictional construction / renovation studio concept created for the Punto Due Studio portfolio.

## Concept

INNESTO is imagined as an Italian integrated renovation studio that keeps survey, spatial design, technical coordination, construction and interior decisions inside one project system.

**Core line:** _Ristrutturare significa scegliere cosa resta._

The site demonstrates a substantially different design problem from the existing Punto Due portfolio: high-consideration service conversion, project storytelling, construction credibility and spatial interaction.

## Signature interaction

The **Section House** is a custom WebGL/Three.js experience derived from a Higgsfield 3D Jutsu scene. The house is organized in four semantic layers:

1. Existing
2. Structure
3. Services
4. Material / finish

Visitors can change phase and drag the scene. Reduced-motion visitors receive a static architectural fallback instead of loading Three.js.
